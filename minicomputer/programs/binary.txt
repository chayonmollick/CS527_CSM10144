% binary.txt - count the 1 bits of a number and write its binary digits
% Task:   Write a program that counts the 1 bits of a number n >= 0 and stores its
%         binary digits, lowest bit first.
% Data:   n at 0
% Result: number of 1 bits at 4; number of binary digits at 8; the digits (0 or 1),
%         lowest bit first, from 12 on
%         binary_data.byte : n = 181 = 10110101b -> [4] = 5, [8] = 8, digits 1 0 1 0 1 1 0 1 at 12 .. 40
%         binary_data2.byte: n = 1024 = 2^10     -> [4] = 1, [8] = 11, digits 0 x 10 then 1
% Method: there is no AND or shift: the lowest bit is n - (n / 2) * 2 and
%         n = n / 2 shifts right by one. n is a power of two when the count is 1.
%         Only for n >= 0 (division rounds towards zero, so negative n goes wrong).
% Regs:   x1 n (shrinks), x2 n / 2, x4 lowest bit, x3 where the next digit goes,
%         x10 ones, x11 digits
x1 = [0]          % n
x10 = 0           % number of 1 bits
x11 = 0           % number of digits
x3 = 12           % where the next digit goes
.loop
x9 = x1 - 0
BEQ .done         % n == 0: no bits left
x2 = x1 / 2
x4 = x2 * 2
x4 = x1 - x4      % lowest bit = n mod 2
[x3] = x4         % store the digit
x10 = x10 + x4    % count the ones
x11 = x11 + 1
x3 = x3 + 4
x1 = x2           % n = n / 2
BAL .loop
.done
[4] = x10
[8] = x11
