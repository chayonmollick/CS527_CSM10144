% linear_search.txt - index of a key in an array, or -1
% Task:   Write a program that searches an array for a key and stores the index of
%         its first occurrence, or -1 if the key is not in the array.
% Data:   N at 0; key at 4; A[0..N-1] at 8 .. 4N + 4
% Result: the index (or -1) at 4N + 8
%         linear_search_data.byte : N = 10, key 25 (at index 2 and 4) -> [48] = 2
%         linear_search_data2.byte: N = 10, key 6 (not there)        -> [48] = -1
% Method: counted loop with an early exit: BEQ leaves the loop as soon as
%         A[i] == key. Constants are 0..255 only, so -1 is made as 0 - 1.
% Variants: last occurrence -> do not exit; remember i in a register on every match.
% Regs:   x1 N, x2 i, x3 &A[i], x4 A[i], x5 key, x6 result address
x1 = [0]          % N
x5 = [4]          % key
x2 = 0            % i
x3 = 8            % &A[0]
.loop
x9 = x2 - x1
BGE .notfound     % i >= N: searched everything
x4 = [x3]
x9 = x4 - x5
BEQ .found        % A[i] == key: x2 is the index
x3 = x3 + 4
x2 = x2 + 1
BAL .loop
.notfound
x2 = 0
x2 = x2 - 1       % -1
.found
x6 = x1 * 4
x6 = x6 + 8       % result address 4N + 8
[x6] = x2         % index or -1
