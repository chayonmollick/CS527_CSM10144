% matvec_rows.txt - one task's block of rows of a PARALLEL MATRIX-VECTOR PRODUCT y = A x (8x8)
% Task:   A is split by rows. Each task gets R consecutive rows of A and its own copy of
%         x, computes those R values of y, and the blocks of y are put together in
%         order afterwards (combine.sh matvec). 4 tasks x 2 rows = the whole product.
% Data:   R (rows in this block) at 0; 4 .. 32 scratch (the 8 lane products);
%         x[0..7] at 36 .. 64; the block's rows of A from 68 (row k at 68 + 32k)
%         matvec1..matvec4.byte: R = 2 (rows 0-1, 2-3, 4-5, 6-7)
%         matvec_all.byte:       R = 8 (the serial run)
% Result: the block's y values right after its rows: y[k] at 68 + 32R + 4k
%         (R = 2: at 132 and 136; R = 8: at 324 .. 352). Each one is also printed.
%         A[i][j] = (3i + 5j) % 11 - 5, x[j] = j - 2  ->  y = 8 -22 25 -38 20 -10 26 -26
%         (matvec1 gives 8 -22, matvec2 25 -38, matvec3 20 -10, matvec4 26 -26)
% Method: VECTOR inside a task: one vector multiply gives the 8 products A[k][j] * x[j];
%         they are stored to the scratch words and added with scalar loads (no
%         instruction adds the lanes of a vector). PARALLEL across tasks: rows.
% Regs:   x1 R, x2 &A[k][0], x3 &y[k], x4 k, x10 y[k], x11 one lane, v1 x, v2 products
v1 = [36]         % x[0..7], loaded once
x1 = [0]          % R
x2 = 68           % &A[0][0] of this block
x3 = x1 * 32
x3 = x3 + 68      % &y[0] = 68 + 32R
x4 = 0            % k
.row
x9 = x4 - x1
BGE .done         % all R rows done
v2 = [x2]         % row k of the block
v2 = v2 * v1      % A[k][j] * x[j] for j = 0..7, one instruction
[4] = v2          % the 8 products -> scratch 4 .. 32
x10 = [4]
x11 = [8]
x10 = x10 + x11
x11 = [12]
x10 = x10 + x11
x11 = [16]
x10 = x10 + x11
x11 = [20]
x10 = x10 + x11
x11 = [24]
x10 = x10 + x11
x11 = [28]
x10 = x10 + x11
x11 = [32]
x10 = x10 + x11
[x3] = x10        % y[k]
print x10
x2 = x2 + 32      % next row
x3 = x3 + 4
x4 = x4 + 1
BAL .row
.done
