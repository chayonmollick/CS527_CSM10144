% Q007 - count the elements greater than the integer average
% Task:   Compute the integer average of an array of N integers (sum / N, the
%         machine's division) and count how many elements are greater than it.
% Data:   N at 0 (N >= 1); A[0..N-1] at 4 .. 4N
% Result: the average at 4N + 4, the count at 4N + 8
%         above_average_data.byte : N = 10, sum 150 -> [44] = 15, [48] = 3
%                                   (30, 25, 41; the 15 is not counted)
%         above_average_data2.byte: N = 5, sum -27  -> [24] = -5, [28] = 2 (-4, -1)
% Method: two passes: add up A, divide once, then count A[i] > average (strictly).
%         The division rounds towards zero, so -27 / 5 = -5, not -6: the element
%         -5 is not counted although it is above the exact average -5.4.
%         Scalar: the count needs a compare per element (no vector compare).
% Regs:   x1 N, x3 pointer, x4 A[i], x6 4N + 4 (end of A), x10 sum, x11 average,
%         x12 count
x1 = [0]          % N
x6 = x1 * 4
x6 = x6 + 4       % 4N + 4: end of A, and the first result
x10 = 0           % sum
x3 = 4
.sum
x9 = x3 - x6
BGE .avg
x4 = [x3]
x10 = x10 + x4
x3 = x3 + 4
BAL .sum
.avg
x11 = x10 / x1    % integer average (rounds towards zero)
x12 = 0           % count
x3 = 4
.count
x9 = x3 - x6
BGE .done
x4 = [x3]
x3 = x3 + 4       % before the compare: an add between compare and branch changes the flags
x9 = x4 - x11
BLE .count        % A[i] <= average: not counted
x12 = x12 + 1
BAL .count
.done
[x6] = x11        % average at 4N + 4
x6 = x6 + 4
[x6] = x12        % count at 4N + 8
