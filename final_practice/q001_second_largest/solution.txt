% Q001 - second largest distinct element and the index of its first occurrence
% Task:   Find the second largest DISTINCT value of an array of N signed integers
%         (the largest value that is smaller than the maximum) and the index (0-based)
%         of its first occurrence. If there is none (all elements are equal, or
%         N = 1), store 0 as the value and -1 as the index.
% Data:   N at 0 (N >= 1); A[0..N-1] at 4, 8, ..., 4N
% Result: second largest at 4N + 4, its index at 4N + 8
%         second_largest_data.byte : N = 12, 45 twice, 41 twice -> [52] = 41, [56] = 3
%         second_largest_data2.byte: N = 5, all -7             -> [24] = 0,  [28] = -1
% Method: one scalar pass keeping (max, its index) and (second, its index):
%           a >  max -> the old max becomes the second, a becomes the max;
%           a == max -> nothing (not a new distinct value);
%           a <  max -> a becomes the second if there is none yet or a > second.
%         Only strictly bigger values replace, so first occurrences are kept.
%         Scalar: the machine has no vector compare.
% Regs:   x1 N, x2 i, x3 &A[i], x4 A[i], x9 compare, x10 max, x11 its index,
%         x12 second, x13 its index (-1 = none yet), x20 zero
x1 = [0]          % N
x3 = 4            % &A[0]
x10 = [x3]        % max = A[0]
x11 = 0           % its index
x12 = 0           % second: stays 0 if none is found
x20 = 0
x13 = x20 - 1     % its index: -1 = no second value yet
x2 = 1            % i = 1 (A[0] is already the max)
.loop
x9 = x2 - x1
BGE .done         % i >= N: every element seen
x3 = x3 + 4       % &A[i]
x4 = [x3]         % a = A[i]
x9 = x4 - x10     % a - max
BEQ .next         % a == max: not a new value
BLT .lower        % a < max (branches do not change the flags)
x12 = x10         % a > max: the old max becomes the second
x13 = x11
x10 = x4          % and a is the new max
x11 = x2
BAL .next
.lower
x9 = x13 - 0
BMI .take         % no second value yet: take a
x9 = x4 - x12     % a - second
BLE .next         % a <= second: keep the old one (first occurrence wins)
.take
x12 = x4          % new second
x13 = x2
.next
x2 = x2 + 1
BAL .loop
.done
x3 = x3 + 4       % x3 was &A[N-1] = 4N, now 4N + 4
[x3] = x12        % second largest value
x3 = x3 + 4
[x3] = x13        % index of its first occurrence
