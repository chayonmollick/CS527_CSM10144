% Q016 - mode of an array of small values (0..15)
% Task:   Every element of an array of N integers is in 0..15. Find the mode (the
%         value that occurs most often) and how often it occurs. If several values
%         occur equally often, the smallest of them is the mode.
% Data:   N at 0 (N >= 1); A[0..N-1] at 4 .. 4N, each 0..15
% Result: mode at 4N + 4, its count at 4N + 8; the 16 counters H[0..15] (scratch)
%         at 4N + 12 .. 4N + 72
%         mode_data.byte : N = 12, 3 and 7 both occur 3 times -> [52] = 3, [56] = 3
%         mode_data2.byte: N = 9, 15 occurs 4 times          -> [40] = 15, [44] = 4
% Method: histogram. Clear the 16 counters with two vector stores of a zero vector,
%         count with H[a] = H[a] + 1 (address H + 4a), then scan v = 0..15 keeping
%         the first largest count: a later value replaces the best only with a
%         strictly larger count, so ties go to the smaller value. O(N + 16).
% Regs:   x1 N, x2 v, x3 &A[i], x4 counter address, x5 a count, x6 4N + 4,
%         x10 mode, x11 its count, x20 H, x21 H + 32, v0 zero vector
x1 = [0]          % N
x6 = x1 * 4
x6 = x6 + 4       % 4N + 4: end of A, and the mode
x20 = x6 + 8      % H = 4N + 12: 16 counters
x21 = x20 + 32    % &H[8]
v0 = v0 - v0      % zero vector
[x20] = v0        % H[0..7] = 0
[x21] = v0        % H[8..15] = 0
x3 = 4            % &A[0]
.count
x9 = x3 - x6
BGE .scan
x4 = [x3]         % a (0..15)
x4 = x4 * 4
x4 = x4 + x20     % &H[a]
x5 = [x4]
x5 = x5 + 1
[x4] = x5         % H[a] = H[a] + 1
x3 = x3 + 4
BAL .count
.scan
x10 = 0           % best value so far: 0
x11 = [x20]       % with count H[0]
x2 = 1            % v = 1
x4 = x20          % &H[v-1]
.sloop
x9 = x2 - 16
BGE .done         % all 16 values seen
x4 = x4 + 4       % &H[v]
x5 = [x4]         % H[v]
x9 = x5 - x11
BLE .snext        % not more than the best: the smaller value stays (ties)
x10 = x2
x11 = x5
.snext
x2 = x2 + 1
BAL .sloop
.done
[x6] = x10        % mode at 4N + 4
x6 = x6 + 4
[x6] = x11        % its count at 4N + 8
