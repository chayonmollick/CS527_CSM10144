% Q008 - maximum subarray sum (Kadane's algorithm)
% Task:   Find the largest sum of a non-empty run of consecutive elements of an
%         array of N integers (they may be negative), and where that run starts
%         and ends.
% Data:   N at 0 (N >= 1); A[0..N-1] at 4 .. 4N
% Result: the maximum sum at 4N + 4, the start index at 4N + 8, the end index at 4N + 12
%         max_subarray_data.byte : N = 9, -2 1 -3 4 -1 2 1 -5 4 -> [40] = 6, [44] = 3, [48] = 6
%         max_subarray_data2.byte: N = 5, all negative          -> [24] = -2, [28] = 3, [32] = 3
% Method: Kadane, one pass. cur = the best sum of a run that ends at i: if the run
%         ending at i-1 has a negative sum it can only hurt, so a new run starts at
%         i; otherwise A[i] extends it. best = the largest cur seen, with the run's
%         start and end. Starting from A[0] (not from 0) makes an all-negative
%         array give its largest element. O(N); trying every run would be O(N^2).
% Regs:   x1 N, x2 i, x3 &A[i], x4 A[i], x10 best, x11 x12 its start and end,
%         x13 cur, x14 start of the current run
x1 = [0]          % N
x3 = 4
x10 = [x3]        % best = A[0]
x11 = 0
x12 = 0           % best run = A[0..0]
x13 = x10         % cur = A[0]
x14 = 0           % the current run starts at 0
x2 = 1            % i
.loop
x9 = x2 - x1
BGE .done
x3 = x3 + 4
x4 = [x3]         % A[i]
x9 = x13 - 0
BPL .extend       % cur >= 0: the run goes on to i
x13 = x4          % cur < 0: drop it, a new run starts at i
x14 = x2
BAL .check
.extend
x13 = x13 + x4    % cur = cur + A[i]
.check
x9 = x13 - x10
BLE .next         % cur <= best: keep the best run found so far
x10 = x13         % new best: the run x14 .. i
x11 = x14
x12 = x2
.next
x2 = x2 + 1
BAL .loop
.done
x3 = x3 + 4       % 4N + 4
[x3] = x10        % maximum sum
x3 = x3 + 4
[x3] = x11        % start index
x3 = x3 + 4
[x3] = x12        % end index
