% Q009 - median of an odd-length array
% Task:   Find the median of an array of N integers, N odd: the middle value of the
%         array once it is sorted. The array itself must not be changed.
% Data:   N at 0 (N odd); A[0..N-1] at 4 .. 4N
% Result: the median at 4N + 4; A is unchanged
%         median_data.byte : N = 9 (sorted: -7 0 3 8 15 15 23 42 99) -> [40] = 15
%         median_data2.byte: N = 5 (sorted: -8 -3 -3 -3 10)          -> [24] = -3
% Method: counting instead of sorting. In sorted order the median has rank
%         k = N / 2 (0-based). For each candidate c = A[i] count less = #(A[j] < c)
%         and leq = #(A[j] <= c); c is the median when less <= k < leq. Testing
%         less == k alone fails with repeated values: in data2 no element has
%         exactly 2 smaller ones. O(N^2) compares, no copy, no swaps.
% Regs:   x1 N, x3 &A[i] (candidate), x4 c, x5 &A[j], x6 4N + 4, x7 A[j],
%         x10 less, x11 leq, x20 k
x1 = [0]          % N
x20 = x1 / 2      % k: the median has k elements before it in sorted order
x6 = x1 * 4
x6 = x6 + 4       % 4N + 4: end of A, and the result
x3 = 4            % first candidate
.cand
x9 = x3 - x6
BGE .done         % (not reached when N is odd: some candidate always fits)
x4 = [x3]         % c = A[i]
x10 = 0           % less
x11 = 0           % leq
x5 = 4            % j = 0
.count
x9 = x5 - x6
BGE .test
x7 = [x5]         % A[j]
x5 = x5 + 4
x9 = x7 - x4      % A[j] - c
BGT .count        % A[j] > c: neither count
BEQ .equal        % A[j] == c (same flags)
x10 = x10 + 1     % A[j] < c
.equal
x11 = x11 + 1     % A[j] <= c
BAL .count
.test
x3 = x3 + 4       % next candidate, in case this one fails
x9 = x10 - x20
BGT .cand         % less > k: c is above the median
x9 = x11 - x20
BLE .cand         % leq <= k: c is below the median
[x6] = x4         % less <= k < leq: c is the median
.done
